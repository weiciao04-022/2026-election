# 政見分類規則（codebook）v0.1

每一條政見是 `data/raw/policies.csv` 的一列。所有候選人都用同一套規則編碼；規則有改動時，在最下方「修訂紀錄」寫明日期和原因，並回頭重編已編過的資料。

## 收錄範圍（第一版）
- 22 縣市長所有登記參選人都列入名單（`candidates.csv`），不只主要政黨。
- 六都：收錄候選人公開的完整政見。
- 其他 16 縣市：先收「現金與補助」類（`type = cash` 或 `subsidy`）政見。
- 只收**候選人本人或競選團隊公開提出**的政見。媒體轉述的，要再找到候選人官網、臉書或記者會的原始出處；找不到就把 `verified` 標成 `N`。

## 欄位定義

| 欄位 | 說明 | 可填的值 |
|---|---|---|
| `policy_id` | 唯一編號 | 縣市代碼-候選人序-流水號，例如 `ILA-01-001` |
| `county_id` | 縣市代碼 | 見 `candidates.csv` |
| `candidate` | 候選人姓名 | 和 `candidates.csv` 完全一致 |
| `title` | 政見名稱 | 盡量用候選人原用語，20 字內 |
| `summary` | 內容摘要 | 自己的話寫，寫出對象、門檻、金額 |
| `issue` | 議題（主要一個） | `child`育兒兒少／`elder`長者長照／`health`醫療健康／`transport`交通／`housing`居住／`education`教育／`economy`產業就業／`environment`環境能源／`safety`治安防災／`governance`市政治理／`culture`文化觀光／`other` |
| `type` | 政見類型 | `cash`直接發錢／`subsidy`費用減免或補助／`infrastructure`建設／`service`新增或擴大服務／`regulation`制度法規／`other` |
| `target` | 受益對象 | 自由文字，例如「65 歲以上設籍長者」 |
| `annual_cost_ntd` | 每年成本（新台幣元） | 數字；沒有就留空 |
| `cost_basis` | 成本口徑 | `annual`每年經常支出／`one_time`一次性（之後換算）／`total_term`四年總額 |
| `cost_source` | 金額來源 | `candidate`候選人自估／`government`政府機關估算／`ours`本站推估（必須在 `cost_note` 寫算式）／`none`未提供 |
| `cost_note` | 金額說明 | 算式、假設、引用原話 |
| `source_url` | 出處網址 | 必填 |
| `source_date` | 出處日期 | YYYY-MM-DD |
| `verified` | 是否已核對原始出處 | `Y`／`N` |
| `checker_note` | 查核備註 | 待查事項、和其他來源不一致處 |

## 判斷規則
1. **一條政見只算一次**。候選人在不同場合重提，留最早、最完整的出處。
2. **cash 和 subsidy 的分界**：拿到的是現金或可自由使用的點數 → `cash`；指定用途的減免、補貼（健保費、掛號費、車資）→ `subsidy`。
3. **議題只選一個主要的**。真的跨議題時，選受益對象最直接相關的那個，並在 `checker_note` 註明。
4. **金額換算成每年**：`one_time` 的建設不換算，網站上和每年支出分開顯示；`total_term` 除以 4，並在 `cost_note` 寫明。
5. **「本站推估」要能重算**：寫出人數 × 單價的來源，例如人口數用內政部戶政司哪個月的資料。推估不了就留空，不硬算。
6. **沒有金額不等於比較便宜**。網站上一律顯示「未提供金額」，不能排在最後或當作 0。

## 成本比例的分母
- 第一版用「116 年度（2027）中央普通統籌分配稅款通知分配金額」（`data/raw/fiscal.csv`）。
- 統籌款只是地方財源的一部分（還有地方稅、規費、補助款），所以網站上寫的是「約占該縣市 2027 年統籌分配稅款的 X%」，**不能寫成「占財政的 X%」或「縣市付不付得起」**。
- 第二版考慮加上各縣市 2027 年總預算的歲出，當作第二個分母。

## 中立原則
- 政黨顏色沿用慣用黨色（民進黨綠、國民黨藍、民眾黨青綠），小黨與無黨籍用中性色；顏色一律搭配政黨簡稱字，不單靠顏色辨識。不使用政黨黨徽。
- 除了顏色，所有候選人的版面、字級、排序規則都相同。
- 同一縣市的候選人依選委會公告號次排列；號次還沒補上之前，依中央社登記名單的順序排列。
- 網站不放民調、不做輸贏預測。
